# Primary Sources Used by the Prototype

This file separates **sourced institutional facts** from **simulated demo configuration**.

## NSDC job role
- Construction Electrician - LV
- QP code: CON/Q0603
- NSQF Level 4 in the NSDC listing surfaced for this role.
- Source: https://nsdcindia.org/nos-export-custom-data

## NSDC PMKK lab infrastructure
NSDC's PMKK page lists a dedicated **Lab Specifications Electrician Construction** resource among its Lab Infrastructure Guidelines:
- https://nsdcindia.org/node/42

The current repository does **not** treat the illustrative quantities in `configs/job_roles/construction_electrician.demo.json` as official quantities. They remain marked simulated until the exact applicable specification table is independently verified.

## Data honesty rule
A sourced job-role name/code does not make the rest of a demo manifest official. Each quantity or compliance threshold must have its own source or remain explicitly marked simulated.
