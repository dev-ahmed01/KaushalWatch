# KaushalWatch — current 60-second controlled judge route

This replaces the previous legacy Network/Cockpit/Reports demo path. The current app has exactly four primary modules: KaushalAI, Centres, Insights and Actions. The one-minute presenter route is INSIDE KaushalAI's guided mission; it does not introduce a fifth app module.

## Preflight on a prepared Windows demo workstation

~~~powershell
.\scripts\Start-KaushalWatch-Judge.ps1 -PreflightOnly
~~~

This verifies all bundled procedural MP4 SHA-256s and the deterministic temporary synthetic seed without deleting active data. For a **demo-only** state that can be safely reseeded, run with -ResetSimulatedState; the guard will refuse real/unidentified records, stray images, unknown settings and stale edge queues. Otherwise launch without that reset option to preserve officer actions. The controlled default starts actual local API/Next without asserting that OpenVINO is authoritative or present.

Open the localhost /demo/mission page. Select **Judge route → 60 sec** and use Next cue (or select each cue directly). Its time windows are planned speaking targets, NOT a stopwatch or measured performance.

If more time is offered, switch to **3m 20s** on the same route to open the saved controlled case, retained evidence SHA, role-gated officer review, persisted audit trail and generated centre PDF. These seeded cases are explicitly synthetic and NOT derived from the procedural sample video shown alongside them.

## Do not overclaim

The bundled recordings are procedurally generated, not live training centre CCTV. Demo attendance and case records are simulated and the offline test is a real localhost request-body measurement, not live WAN throughput. Missing independent attendance, equipment, practical work and camera-trust held-out ground truth means field model accuracy is **NOT QUALIFIED**. A green CI run, case SHA or source playback does not certify a government institution or justify automatic financial sanctions.

The full current operator/Windows reset instructions are in [Phase 6 submission runbook](../release/PHASE6_SUBMISSION_JUDGE_RUNBOOK.md). If the source validation or protected officer gate fails, STOP and diagnose the cause; do not substitute arbitrary footage, invented counts or manually copied evidence.
