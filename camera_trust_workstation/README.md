# KaushalWatch Camera Trust — Source Mirror

This is the code-only mirror of the unified Camera Trust research workstation.
The reproducible full release ZIP includes the privately sourced numerical
reports and the approved Drive file manifest. Those are intentionally **not**
committed to the public repository. No AVI/MP4, credentials, person frames,
Google Drive file IDs, camera references, or source evidence are included.

Functions: read-only source-pinned numerical dashboard, fixed-time unlabeled
scene probing, source clip evaluation, resumable read-only Google Drive
downloader, full research acceptance gate and fail-closed Docker startup.

This component cannot be promoted to physical tampering enforcement by CI
alone. Field-qualified custody, independent source labels and safe incident
review must be established before any operational integration.

Use the private complete deliverable ZIP for a ready-to-run local dashboard
with already evaluated source-pinned research output. From that directory,
execute `Start-Workstation.ps1`. This public code-only mirror requires the
separately supplied `drive-sources.json`, `example_data/`, and `out/` data
directories to run its read-only research server.

CI tests only synthetic sources to avoid publishing confidential recordings.
